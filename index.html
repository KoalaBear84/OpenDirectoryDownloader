Use the URLs file with wget or aria2.

# Windows
OpenDirectoryDownloader.exe --url "https://myopendirectory.com"

# Linux / macOS
./OpenDirectoryDownloader --url "https://myopendirectory.com"
# Download with wget
wget -x -i theurlsfile.txt

# Download with aria2 (keeps folders)
aria2c -i theurlsfile-aria2.txt

Short options combine: -qcj is -q -c -j. Press I during a scan for the key commands.
