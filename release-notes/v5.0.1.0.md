## CrushFTP

- **Servers behind Cloudflare or another proxy** are now recognized as CrushFTP. Before, they were scanned as a plain web page and nothing was found.
- **Servers that send numbers as text** (like `"size": "1234"`) can be scanned. Before, the scan failed on the first directory.
- **Names with `#`, `?`, `%` or a backslash** work. Before, such a directory failed or was cut off at the `#`.
- **A link copied from the browser** like `https://host/#/Folder/Subfolder/` now scans that folder, instead of the whole server.
- **No more limit of 1 directory per second.** Scans are as fast as the number of threads allows. If a server does slow you down or ban you, use `--threads 1` or `--wait`.
