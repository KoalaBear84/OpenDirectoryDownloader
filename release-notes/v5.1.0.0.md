## .NET 11

- OpenDirectoryDownloader now runs on **.NET 11**. The self-contained downloads need nothing extra. If you use the version that is not self-contained, install the .NET 11 runtime: https://dotnet.microsoft.com/download/dotnet/11.0/runtime
- The Docker image uses .NET 11.

## Updates

- All components are updated to their latest versions: the HTML reader, the JavaScript engine, FTP, the Google Drive connection, the retry logic, the command line and the browser impersonation (`--http-cloak`).
